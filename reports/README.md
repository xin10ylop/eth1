# Reports

| folder | contents |
|---|---|
| `holdout/` | **headline results**: frozen 6-month holdout (2026-05 → 2026-10). Includes `holdout_<variant>_<target>.json` (core/sat/ensemble metrics, monthly IC, calibration, bootstrap tests), `summary_holdout*.json` (latency decay, hit by confidence, regimes) and `edge_vs_costs.json`. |
| `confirm/` | the untouched DEV confirmation months (2025-12, 2026-02, 2026-04) |
| `figures/` | charts used in the README |
| `dev/` | research runs on the DEV months: `results.jsonl` (one line per experiment, with its args), `imp_*.csv` feature importances |
| `research/` | mechanism studies (ETH vs BTC lead-lag, efficiency, family IC scans), calibration and regime studies |
| `live/` | live forward-test logs |
| `preds/` | cached out-of-sample predictions (not in git; regenerated by the scripts) |

Regenerate tables and charts with `make reports`.
